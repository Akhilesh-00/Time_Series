# LITE Time-Series Project

This repository contains our reproduction and exploratory evaluation of **LITE**, a lightweight deep-learning model for time-series classification.

## Start here

The active project, setup instructions, experiment commands, and results are documented in [LITE-main/README.md](LITE-main/README.md). The latest consolidated findings are in [LITE-main/experiment_results/FINAL_RESULTS.md](LITE-main/experiment_results/FINAL_RESULTS.md).

Our work builds on the LITE implementation and research by Ismail-Fawaz et al. See the project README for attribution and links to the original papers.
